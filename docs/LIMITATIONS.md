# Known Limitations

## Platform Coverage

- Linux and Windows are the current release targets.
- macOS is not an officially supported target in this release.

## Media And Playback

- Some codecs and containers depend on system GStreamer plugin availability.
- Hardware acceleration support depends on OS/driver stack.
- Live-stream style media without duration may have limited seek behavior.

## UX Scope (Initial Public Release)

- No built-in automatic updater yet.
- Advanced settings UI is limited.
- Error messages are improving but not exhaustive for every backend failure.

## API/Feature Scope

- Focus is on Plex core browsing/playback workflows.
- Not all Plex ecosystem features are implemented yet.
